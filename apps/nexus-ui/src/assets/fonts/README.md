# Fuentes de NEXUS

`nexus_font_16.c` y `nexus_font_28.c` son subconjuntos LVGL de Montserrat Medium, generados con `lv_font_conv` 1.5.3. Incluyen ASCII, Latin-1 y el punto medio usado en la barra de estado para renderizar correctamente los textos en español.

La fuente de origen es `scripts/built_in_font/Montserrat-Medium.ttf` de LVGL v9.2.2. Montserrat está licenciada bajo SIL Open Font License 1.1; la licencia completa está en `OFL.txt`.
