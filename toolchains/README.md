# Toolchains

Área para archivos de configuración de compiladores cruzados y plataformas objetivo. La primera plataforma prevista es Linux ARM para la compilación Armbian propia de R36S.

## Fases

- Fase 0: documentar la plataforma y dependencias conocidas, sin inventar versiones.
- Fase 8: añadir y validar toolchain C++ y configuración Go contra el entorno Armbian real.

La compilación de escritorio continúa siendo el camino inicial de desarrollo.
